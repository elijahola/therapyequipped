TEMPLATE SETTINGS IN EMAILJS:
================================================

1. To Email: therapyequipped@gmail.com
   (or use variable: {{to_email}})

3. Reply To: {{customer_email}}
   (This allows you to reply directly to the customer)

================================================

VARIABLES USED (automatically filled by system):
================================================

{{customer_name}}     - Full name of customer
{{customer_email}}    - Customer's email address
{{customer_phone}}    - Customer's phone (if collected)
{{customer_address}}  - Full shipping address
{{order_items}}       - List of ordered items with quantities
{{subtotal}}          - Order subtotal
{{shipping}}          - Shipping cost (or "FREE")
{{total}}             - Total amount
{{order_date}}        - Date and time of order
{{to_email}}          - Recipient email (therapyequipped@gmail.com)

================================================

QUICK SETUP STEPS:
================================================

1. Go to EmailJS Dashboard
2. Click "Email Templates"
3. Click "Create New Template"
4. Copy the HTML above into the "Content" field
5. Copy the subject line into "Subject" field
6. Set "To Email" to: therapyequipped@gmail.com
7. Set "Reply To" to: {{customer_email}}
8. Save template
9. Copy Template ID to .env file
